## Variable Pattern

| Name | Meaning |
|---|---|
| root | root of the tree |
| res | values of each level, in zigzag order |
| level | nodes of the current level, left to right |
| values | values of the current level |
| next | nodes of the following level, left to right |
| node | node whose children are collected |
