## Variable Pattern

| Name | Meaning |
|---|---|
| root | root of the tree |
| targetSum | sum a root-to-leaf path must reach |
| stack | nodes still to visit, each with the sum of its path from the root |
| node | node being visited |
| sum | sum of the path from the root to node |
