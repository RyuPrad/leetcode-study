## Variable Pattern

| Name | Meaning |
|---|---|
| `p` | current node in the first tree |
| `q` | current node in the second tree (compared against `p`) |
| `p.val` / `q.val` | values being compared at this node |
| `ans` | boolean result: are the two trees identical |
