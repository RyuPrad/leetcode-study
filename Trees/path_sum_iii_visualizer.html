437. Path Sum III Visualizer

Count every nonempty downward path whose values add to a target. Paths may start or end anywhere. Follow one ancestor branch, count matching prefix sums, then remove that branch's prefix before returning.

Reference Solution

function pathSum(root, targetSum) {
const freq = new Map();
freq.set(0, 1);
let count = 0;
function dfs(node, sum) {
if (node === null) {
return;
}
sum += node.val;
const need = sum - targetSum;
const matches = freq.get(need) || 0;
count += matches;
freq.set(sum, (freq.get(sum) || 0) + 1);
dfs(node.left, sum);
dfs(node.right, sum);
freq.set(sum, freq.get(sum) - 1);
if (freq.get(sum) === 0) {
freq.delete(sum);
}
return;
}
dfs(root, 0);
return count;
}

How It Works

A path ending here sums to target when earlierPrefix = currentPrefix - targetSum. The Map counts earlier prefixes on this branch only.
  1. Seed prefix 0 once to count paths beginning at the root.
  2. Read the matching frequency before inserting the current prefix. This excludes empty paths when the target is zero.
  3. Add the full frequency, because equal prefixes can represent different starting points.
  4. Visit both children, then remove exactly this call's one prefix occurrence. Ancestors stay available; siblings do not share completed branches.

Visualizer limits: 63 non-null nodes and 127 level-order entries, node values from -1,000,000,000 to 1,000,000,000, and target from -1,000 to 1,000. Use null for absent children, or [] for an empty tree. Coding supports up to 1,000 nodes. These bounds keep all prefix arithmetic exact in JavaScript.
