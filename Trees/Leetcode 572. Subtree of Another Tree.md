## Variable Pattern

| Name | Meaning |
|---|---|
| `root` | root of the main tree being searched |
| `subRoot` | root of the pattern tree we look for |
| `node` | current candidate node in `root` where we test for an exact match |
| `ans` | boolean result: is `subRoot` a subtree of `root` |
