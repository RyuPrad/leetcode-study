## Variable Pattern

| Name | Meaning |
|---|---|
| nums | input values, sorted in place |
| k | number of +1 operations allowed |
| left | first index of the window |
| right | last index of the window; every value is raised to nums[right] |
| total | sum of the window values |
| res | largest valid window size so far |
