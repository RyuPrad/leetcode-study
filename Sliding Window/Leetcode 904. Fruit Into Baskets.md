## Variable Pattern

| Name | Meaning |
|---|---|
| fruits | fruit type of each tree |
| count | fruit type → trees of that type in the window |
| left | first tree in the window |
| right | tree being picked |
| fruit | type leaving the window |
| res | most fruit collected so far |
