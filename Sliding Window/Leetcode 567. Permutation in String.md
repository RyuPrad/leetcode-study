## Variable Pattern

| Name | Meaning |
|---|---|
| s1 | pattern string whose permutation we search for |
| s2 | text string we slide the window across |
| need | character frequencies of s1 the window must match |
| window | character frequencies inside the current fixed-width window |
| left | left bound of the window |
| right | right bound of the window |
