## Variable Pattern

| Name | Meaning |
|---|---|
| nums | n distinct binary strings of length n |
| seen | set of those strings |
| n | their length |
| build | returns a missing string that starts with current, or null |
| current | prefix being built |
| withZero | result of continuing with "0" |
