## Variable Pattern

| Name | Meaning |
|---|---|
| `board` | the grid of letters |
| `word` | the word we are trying to spell |
| `rows` | number of rows in `board` |
| `cols` | number of columns in `board` |
| `r` | current row during DFS |
| `c` | current column during DFS |
| `i` | index of the letter in `word` we need next |
