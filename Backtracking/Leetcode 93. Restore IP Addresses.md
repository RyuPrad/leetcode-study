## Variable Pattern

| Name | Meaning |
|---|---|
| s | the digits |
| res | valid addresses found |
| parts | parts chosen so far |
| backtrack | tries every next part starting at start |
| start | index where the next part begins |
| len | length of the next part |
| part | the next part |
