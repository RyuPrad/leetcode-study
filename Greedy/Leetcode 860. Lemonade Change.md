## Variable Pattern

| Name | Meaning |
|---|---|
| `bills` | Input array of bills handed over in order (each is 5, 10, or 20). |
| `five` | Count of $5 bills currently in the register. |
| `ten` | Count of $10 bills currently in the register. |
| `bill` | The current bill being processed in the loop. |
| `ans` | Result: `true` if we can give correct change to every customer, else `false`. |
