## Variable Pattern

| Name | Meaning |
|---|---|
| dist | starting distance of each monster from the city |
| speed | distance each monster covers per minute |
| arrival | first minute at which each monster is at the city |
| i | monster whose arrival is computed |
| minute | minute of the next shot |
