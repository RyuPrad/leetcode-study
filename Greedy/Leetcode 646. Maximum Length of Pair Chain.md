## Variable Pattern

| Name | Meaning |
|---|---|
| pairs | pairs [left, right], sorted by right |
| res | pairs in the chain so far |
| end | right end of the last pair in the chain |
| left | left value of the pair being considered |
| right | right value of the pair being considered |
