## Variable Pattern

| Name | Meaning |
|---|---|
| `nums` | input array of numbers |
| `k` | which largest element to return (the kth largest) |
| `heap` | a MinHeap capped at size k, holding the k largest values seen so far |
| `num` | the current number from `nums` being pushed onto the heap |
