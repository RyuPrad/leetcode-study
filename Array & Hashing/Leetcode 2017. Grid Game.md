## Variable Pattern

| Name | Meaning |
|---|---|
| grid | 2 × n points |
| n | number of columns |
| top | points left on the top row after the first robot turns down |
| bottom | points left on the bottom row before the turn |
| res | smallest score the second robot can be held to |
| i | column where the first robot moves down |
