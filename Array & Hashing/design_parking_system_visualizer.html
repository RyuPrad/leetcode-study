1603. Design Parking System

Free spaces counted by car type

Live Debugger

class ParkingSystem {
constructor(big, medium, small) {
this.spaces = [0, big, medium, small];
}
addCar(carType) {
if (this.spaces[carType] === 0) {
return false;
}
this.spaces[carType]--;
return true;
}
}
