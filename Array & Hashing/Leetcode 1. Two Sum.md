## Variable Pattern

| Name | Meaning |
|---|---|
| nums | input array |
| target | value we need two numbers to sum to |
| i | current index |
| num | value at nums[i] |
| need | complement: target - num |
| seen | map of value → index already visited |
| res | returned index pair |
