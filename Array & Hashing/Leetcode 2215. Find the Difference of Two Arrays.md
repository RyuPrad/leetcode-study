## Variable Pattern

| Name | Meaning |
|---|---|
| nums1 | first array |
| nums2 | second array |
| set1 | distinct values of nums1 |
| set2 | distinct values of nums2 |
| only1 | values in nums1 but not nums2 |
| only2 | values in nums2 but not nums1 |
