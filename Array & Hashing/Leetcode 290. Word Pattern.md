## Variable Pattern

| Name | Meaning |
|---|---|
| pattern | letters, one per word |
| s | words separated by single spaces |
| words | s split into words |
| charToWord | pattern letter → word |
| wordToChar | word → pattern letter |
| i | position compared |
| c | pattern[i] |
| word | words[i] |
