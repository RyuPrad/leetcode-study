## Variable Pattern

| Name | Meaning |
|---|---|
| s | string searched |
| p | pattern whose anagrams are found |
| res | start indices of anagrams |
| need | letter counts of p |
| have | letter counts of the current window of s |
| i | index while counting the first window |
| right | index entering the window |
