## Variable Pattern

| Name | Meaning |
|---|---|
| text | available letters |
| count | letter → how many times it appears |
| c | letter being counted or checked |
| need | letters per "balloon": b, a, n once; l, o twice |
| res | balloons the scarcest letter allows |
