## Variable Pattern

| Name | Meaning |
|---|---|
| flowerbed | plots: 1 has a flower, 0 is empty |
| n | flowers to plant |
| count | flowers planted so far |
| i | plot being considered |
| leftEmpty | the plot to the left is empty or absent |
| rightEmpty | the plot to the right is empty or absent |
