var groupAnagrams = function(strs) {
const groups = new Map();
for (const str of strs) {
const count = new Array(26).fill(0);
for (const char of str) {
const index = char.charCodeAt(0) - 97;
count[index]++;
}
const key = count.join("#");
if (!groups.has(key)) groups.set(key, []);
groups.get(key).push(str);
}
return Array.from(groups.values());
};

Algorithm Flow (Frequency Count Approach)

  • 1For each word, create a frequency array of size 26 initialized to 0.
  • 2Count how many times each lowercase letter appears.
  • 3Convert the frequency array to a string key using # as a delimiter.
  • 4Use the key in a HashMap. Same key means same anagram group.
  • 5Return all groups from groups.values().

Time & Space Complexity

Time Complexity: O(n * k)
// n = number of strings
// k = average string length

Space Complexity: O(n * k)
// stores all strings in grouped lists
