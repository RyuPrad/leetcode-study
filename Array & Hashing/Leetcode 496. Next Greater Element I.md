## Variable Pattern

| Name | Meaning |
|---|---|
| nums1 | queried values, a subset of nums2 |
| nums2 | values scanned left to right |
| next | value → its next greater value in nums2 |
| stack | values still waiting for a greater value, decreasing |
| num | value being scanned |
