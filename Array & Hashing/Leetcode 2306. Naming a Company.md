## Variable Pattern

| Name | Meaning |
|---|---|
| ideas | distinct candidate names |
| groups | first letter → set of suffixes |
| idea | name being grouped |
| first | its first letter |
| suffix | the rest of the name |
| letters | first letters that occur |
| res | valid names counted so far |
| a | index of the first group in a pair |
| b | index of the second group |
| setA | suffixes after letters[a] |
| setB | suffixes after letters[b] |
| shared | suffixes found in both groups |
