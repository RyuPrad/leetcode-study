## Variable Pattern

| Name | Meaning |
|---|---|
| board | 8 × 8 board of ".", "W" and "B" |
| rMove | row of the move |
| cMove | column of the move |
| color | color being played |
| other | the opposite color |
| dirs | the eight directions |
| dr | row step of the direction |
| dc | column step |
| r | row being looked at |
| c | column being looked at |
| length | cells in the line so far, counting the move |
