## Variable Pattern

| Name | Meaning |
|---|---|
| n | number of nodes |
| edges | directed edges [from, to] |
| hasIncoming | whether some edge points into each node |
| to | target of the edge being read |
| res | nodes with no incoming edge |
| node | node being checked |
