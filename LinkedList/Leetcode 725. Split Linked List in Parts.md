## Variable Pattern

| Name | Meaning |
|---|---|
| head | first node of the list |
| k | number of parts |
| length | number of nodes |
| node | node being counted |
| size | nodes every part gets |
| extra | parts that get one more node |
| res | head of each part |
| curr | node being placed |
| i | part being built |
| partSize | nodes in part i |
| j | position of curr inside the part |
| next | first node of the following part |
