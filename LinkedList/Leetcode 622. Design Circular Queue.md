## Variable Pattern

| Name | Meaning |
|---|---|
| `queue` | fixed-size backing array of length `capacity` |
| `head` | index of the front element |
| `count` | number of elements currently in the queue |
| `capacity` | maximum number of elements (`k`) |
| `value` | value passed to `enQueue` |
