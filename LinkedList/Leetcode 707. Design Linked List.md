## Variable Pattern

| Name | Meaning |
|---|---|
| this.dummy | extra node before the first real node |
| this.size | number of real nodes |
| index | position of the node to read, insert or delete |
| val | value to insert |
| curr | node being walked to (get) |
| prev | node just before the position (insert and delete) |
| i | steps taken so far |
