## Variable Pattern

| Name | Meaning |
|---|---|
| head | next node to place |
| x | partition value |
| lessHead | dummy before the nodes smaller than x |
| moreHead | dummy before the nodes at least x |
| less | last node of the smaller list |
| more | last node of the larger list |
