## Variable Pattern

| Name | Meaning |
|---|---|
| head | first node of the list |
| k | places to rotate right |
| length | number of nodes |
| tail | last node |
| newTail | node that becomes the last node |
| i | position of newTail while it walks |
| newHead | node that becomes the first node |
