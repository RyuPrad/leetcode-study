## Variable Pattern

| Name | Meaning |
|---|---|
| head | first node of the unsorted list |
| dummy | extra node before the sorted list |
| curr | node being inserted |
| next | rest of the unsorted list, saved before curr is moved |
| prev | last sorted node smaller than curr |
