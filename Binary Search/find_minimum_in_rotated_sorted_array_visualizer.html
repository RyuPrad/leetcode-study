153. Find Minimum in Rotated Sorted Array Visualizer

A sorted array nums was rotated at some pivot. Find the minimum element in O(log n) by comparing nums[mid] with nums[right] to decide which half still holds the minimum.

var findMin = function(nums) {
let left = 0;
let right = nums.length - 1;
while (left < right) {
const mid = Math.floor((left + right) / 2);
if (nums[mid] > nums[right]) {
left = mid + 1;
} else {
right = mid;
}
}
return nums[left];
};

Iteration Trace

How It Works

mid = floor((left + right) / 2)
If nums[mid] > nums[right] -> min is to the right -> left = mid + 1
Else nums[mid] <= nums[right] -> min is at mid or left -> right = mid
Loop while left < right; answer is nums[left].
  1. Compare the middle value to the rightmost value.
  2. If mid is bigger, the rotation pivot (and minimum) is to the right.
  3. If mid is smaller or equal, the minimum is mid or to its left.
  4. Never discard mid when moving right, because mid could be the minimum.
  5. Stop when left meets right; that single cell is the minimum.
