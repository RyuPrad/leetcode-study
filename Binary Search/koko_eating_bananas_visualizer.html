875. Koko Eating Bananas Visualizer

Koko eats bananas at mid per hour. Binary search the eating speed in the range [1, max(piles)]. For each candidate mid, the feasibility check sums ceil(p / mid) hours over all piles; if that total is <= h the speed works, so we record ans and try slower.

var minEatingSpeed = function(piles, h) {
let left = 1;
let right = Math.max(...piles);
let ans = right;
while (left <= right) {
const mid = Math.floor((left + right) / 2);
let hours = 0;
for (const p of piles) {
hours += Math.ceil(p / mid);
}
if (hours <= h) {
ans = mid;
right = mid - 1;
} else {
left = mid + 1;
}
}
return ans;
};

Iteration Trace

How It Works

mid = floor((left + right) / 2) // candidate speed
hours = sum of ceil(p / mid) over piles
If hours <= h → speed works: ans = mid, search slower (right = mid - 1)
If hours > h → too slow: search faster (left = mid + 1)
  1. The answer is a speed between 1 and the largest pile.
  2. Slower speed means more hours; faster speed means fewer hours.
  3. hours is monotonic, so binary search applies to the speed.
  4. Record the smallest feasible speed and keep shrinking from the right.
  5. Stop when left passes right; ans holds the minimum speed.
