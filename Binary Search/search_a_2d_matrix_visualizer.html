Each row of matrix is sorted, and the first value of each row is greater than the last value of the previous row. So the whole matrix behaves like one sorted array of length m * n. Binary search that virtual array, mapping the 1-D index mid to row = floor(mid / n), col = mid % n.

var searchMatrix = function(matrix, target) {
const m = matrix.length;
const n = matrix[0].length;
let left = 0;
let right = m * n - 1;
while (left <= right) {
const mid = Math.floor((left + right) / 2);
const val = matrix[Math.floor(mid / n)][mid % n];
if (val === target) {
return true;
} else if (val < target) {
left = mid + 1;
} else {
right = mid - 1;
}
}
return false;
};

Step Trace

How It Works

mid = floor((left + right) / 2)
row = floor(mid / n), col = mid % n
If matrix[row][col] === target → return true
If matrix[row][col] < target → search right half
If matrix[row][col] > target → search left half
  1. Flatten the matrix into one sorted array of length m * n.
  2. Binary search the linear index range [0, m*n - 1].
  3. Convert mid back to a (row, col) to read the value.
  4. Discard the half that cannot contain the target.
  5. Stop when the value matches or the range becomes empty.
