374. Guess Number Higher or Lower Visualizer

We pick a number from 1 to n. Each call to guess(num) returns 0 if num is the pick, -1 if num is too high, and 1 if num is too low. Binary search the range [1, n] to find the pick.

var guessNumber = function(n) {
let left = 1;
let right = n;
while (left <= right) {
const mid = Math.floor((left + right) / 2);
const res = guess(mid);
if (res === 0) {
return mid;
} else if (res < 0) {
right = mid - 1;
} else {
left = mid + 1;
}
}
return -1;
};

Step Trace

How It Works

mid = floor((left + right) / 2)
guess(mid) === 0 → mid is the pick, return mid
guess(mid) === -1 (too high) → search the lower half
guess(mid) === 1 (too low) → search the upper half
  1. Start with the whole range [1, n].
  2. Guess the middle number.
  3. If the guess is too high, discard the upper half.
  4. If the guess is too low, discard the lower half.
  5. Stop as soon as guess(mid) returns 0.
