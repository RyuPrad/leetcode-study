1011. Capacity to Ship Packages Within D Days Visualizer

Find the least ship capacity that delivers all weights in order within days days. Binary search the capacity in the range [max(weights), sum(weights)]. For each candidate mid, greedily pack packages into days; if the resulting day count is <= days the capacity works, so record ans and try a smaller capacity.

var shipWithinDays = function(weights, days) {
let left = Math.max(...weights);
let right = weights.reduce((a, b) => a + b, 0);
let ans = right;
while (left <= right) {
const mid = Math.floor((left + right) / 2);
let need = 1;
let cur = 0;
for (const w of weights) {
if (cur + w > mid) {
need++;
cur = 0;
}
cur += w;
}
if (need <= days) {
ans = mid;
right = mid - 1;
} else {
left = mid + 1;
}
}
return ans;
};

How It Works

mid = floor((left + right) / 2) // candidate capacity
Greedily fill a day until adding the next weight exceeds mid, then start a new day.
If need <= days → capacity works: ans = mid, shrink (right = mid - 1)
If need > days → too small: grow (left = mid + 1)
  1. Capacity must be at least the heaviest package and at most the total.
  2. Bigger capacity fits more per day, so fewer days are needed.
  3. The number of days is monotonic, so binary search applies.
  4. Record the smallest capacity that still fits within days.
  5. Stop when left passes right; ans holds the minimum capacity.
