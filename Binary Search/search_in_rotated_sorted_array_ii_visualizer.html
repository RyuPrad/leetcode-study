81. Search in Rotated Sorted Array II Visualizer

A rotated sorted array nums may contain duplicates. Return true if target exists. The new twist: when nums[left] === nums[mid] === nums[right] we cannot tell which half is sorted, so we shrink both ends.

var search = function(nums, target) {
let left = 0;
let right = nums.length - 1;
while (left <= right) {
const mid = Math.floor((left + right) / 2);
if (nums[mid] === target) {
return true;
}
if (nums[left] === nums[mid] && nums[mid] === nums[right]) {
left++;
right--;
} else if (nums[left] <= nums[mid]) {
if (nums[left] <= target && target < nums[mid]) {
right = mid - 1;
} else {
left = mid + 1;
}
} else {
if (nums[mid] < target && target <= nums[right]) {
left = mid + 1;
} else {
right = mid - 1;
}
}
}
return false;
};

Iteration Trace

How It Works

mid = floor((left + right) / 2)
If nums[mid] === target -> return true
If nums[left] === nums[mid] === nums[right] -> ambiguous: left++, right--
Else if nums[left] <= nums[mid] -> left half sorted
Else -> right half sorted
  1. Find mid and check if it equals the target.
  2. If the three ends are equal we cannot tell the sorted side.
  3. In that ambiguous case, trim one element off each end and retry.
  4. Otherwise pick the sorted half and test the target range.
  5. Stop when found (true) or the window empties (false).
