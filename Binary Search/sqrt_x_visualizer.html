69. Sqrt(x) Visualizer

Given a non-negative integer x, return the integer square root of x rounded down (floor). Binary search the candidate range [0, x]: for each mid, compare mid * mid to x.

var mySqrt = function(x) {
let left = 0;
let right = x;
let ans = 0;
while (left <= right) {
const mid = Math.floor((left + right) / 2);
if (mid * mid <= x) {
ans = mid;
left = mid + 1;
} else {
right = mid - 1;
}
}
return ans;
};

Step Trace

How It Works

mid = floor((left + right) / 2)
If mid * mid <= x → mid is a valid answer, record it and search higher
If mid * mid > x → mid is too big, search lower
The last recorded ans is floor(sqrt(x))
  1. Start with the whole range [0, x].
  2. Square the middle value and compare it to x.
  3. If mid * mid <= x, mid still fits, so save it and look for a larger root.
  4. If mid * mid > x, mid overshoots, so look lower.
  5. Return the largest value whose square did not exceed x.
