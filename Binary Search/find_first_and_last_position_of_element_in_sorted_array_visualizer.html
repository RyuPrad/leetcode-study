34. Find First and Last Position of Element in Sorted Array Visualizer

Find the complete run of a target in a sorted array, including duplicates. Use two half-open binary searches: the first value ≥ target and the first value > target. Return their inclusive index range, or [-1, -1] when absent.

/**
* @param {number[]} nums
* @param {number} target
* @return {number[]}
*/
var searchRange = function(nums, target) {
let left = 0;
let right = nums.length;
while (left < right) {
const mid = left + Math.floor((right - left) / 2);
if (nums[mid] < target) {
left = mid + 1;
} else {
right = mid;
}
}
const first = left;
left = 0;
right = nums.length;
while (left < right) {
const mid = left + Math.floor((right - left) / 2);
if (nums[mid] <= target) {
left = mid + 1;
} else {
right = mid;
}
}
const afterLast = left;
if (first === nums.length || nums[first] !== target) {
return [-1, -1];
}
return [first, afterLast - 1];
};

Step Trace

How It Works

Search window: [left, right)
Lower bound: first index with nums[i] ≥ target
Upper bound: first index with nums[i] > target
Answer: [first, afterLast - 1] after checking target exists
  1. Start with left = 0 and right = nums.length. The right endpoint is excluded.
  2. For the lower bound, values below target move left = mid + 1. Otherwise set right = mid, preserving the boundary candidate.
  3. When the bounds meet, save first. Reset both bounds to search the whole array again.
  4. For the upper bound, values equal to target also move left forward. Save afterLast when the bounds meet.
  5. Verify the target exists at first. Return the inclusive range or [-1, -1].

The dashed n slot is a boundary, never an array value. Neither loop reads nums[n]. Empty arrays finish safely with both boundaries at zero.
