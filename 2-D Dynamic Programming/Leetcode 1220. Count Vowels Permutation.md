## Variable Pattern

| Name | Meaning |
|---|---|
| n | length of the strings |
| MOD | 10^9 + 7 |
| a | strings of the current length ending in "a" |
| e | strings ending in "e" |
| i | strings ending in "i" |
| o | strings ending in "o" |
| u | strings ending in "u" |
| len | length being built |
| na | new count ending in "a" |
| ne | new count ending in "e" |
| ni | new count ending in "i" |
| no | new count ending in "o" |
| nu | new count ending in "u" |
