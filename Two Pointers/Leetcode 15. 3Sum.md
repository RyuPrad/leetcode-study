## Variable Pattern

| Name | Meaning |
|---|---|
| nums | sorted input array |
| res | unique triplets that sum to 0 |
| i | fixed outer index |
| left | left pointer |
| right | right pointer |
| sum | nums[i] + nums[left] + nums[right] |
