881. Boats to Save People

Each boat carries at most two people and a total weight up to limit. Sort people ascending, then pair the lightest (left) with the heaviest (right). Count the minimum number of boats.

var numRescueBoats = function(people, limit) {
people.sort((a, b) => a - b);
let left = 0;
let right = people.length - 1;
let boats = 0;
while (left <= right) {
if (people[left] + people[right] <= limit) {
left++;
}
right--;
boats++;
}
return boats;
};

Iteration Trace

How It Works

  1. Sort people ascending so the lightest and heaviest sit at the two ends.
  2. left points at the lightest remaining, right at the heaviest remaining.
  3. If people[left] + people[right] <= limit, both share one boat (left++).
  4. Either way the heaviest always boards now, so right-- and boats++ every step.
  5. Stop when left > right and return boats.
