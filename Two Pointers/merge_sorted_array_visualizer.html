Leetcode 88. Merge Sorted Array

DRAG CONTROLS

nums1 & nums2 + Three Pointers (merge from the back)

Why merge from the back? The free space in nums1 is at the end. If we wrote from the front we would overwrite real nums1 values before reading them. Writing the largest values into the empty tail first means index k is always at or ahead of i, so no unread value is ever clobbered.

var merge = function(nums1, m, nums2, n) {
let i = m - 1;
let j = n - 1;
let k = m + n - 1;
while (j >= 0) {
if (i >= 0 && nums1[i] > nums2[j]) {
nums1[k] = nums1[i];
i--;
} else {
nums1[k] = nums2[j];
j--;
}
k--;
}
};
