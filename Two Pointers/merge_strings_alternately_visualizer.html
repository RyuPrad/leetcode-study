1768. Merge Strings Alternately

Merge two strings by adding letters in alternating order, starting with word1. If one string is longer, append the remaining letters onto the end.

var mergeAlternately = function(word1, word2) {
let i = 0;
let j = 0;
let res = [];
while (i < word1.length || j < word2.length) {
if (i < word1.length) {
res.push(word1[i]);
i++;
}
if (j < word2.length) {
res.push(word2[j]);
j++;
}
}
return res.join("");
};

Step Trace

How It Works

  1. Pointers i and j start at 0.
  2. Each loop pass takes one char from word1, then one from word2.
  3. Only push if that pointer is still in range.
  4. When a string is exhausted, the other keeps appending.
  5. Finally, res.join("") is the answer.
