680. Valid Palindrome II

Given a string s, return true if it can be a palindrome after deleting at most one character. Two pointers converge; on the first mismatch we branch into two sub-checks.

var validPalindrome = function(s) {
let left = 0;
let right = s.length - 1;
while (left < right) {
if (s[left] !== s[right]) {
return isPalindrome(s, left + 1, right) ||
isPalindrome(s, left, right - 1);
}
left++;
right--;
}
return true;
};
function isPalindrome(s, left, right) {
while (left < right) {
if (s[left] !== s[right]) return false;
left++;
right--;
}
return true;
}

Step Trace

How It Works

  1. Use two pointers: left at the start and right at the end.
  2. While characters match, move both pointers inward.
  3. On the first mismatch, you may delete one character.
  4. Try skipping left (check [left+1, right]) OR skipping right (check [left, right-1]).
  5. If either sub-check is a palindrome, return true.
