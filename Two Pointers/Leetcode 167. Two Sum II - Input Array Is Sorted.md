## Variable Pattern

| Name | Meaning |
|---|---|
| numbers | sorted (1-indexed) input array |
| target | value the two numbers must add up to |
| left | left pointer, starts at index 0 |
| right | right pointer, starts at the last index |
| sum | numbers[left] + numbers[right] |
| res | returned 1-based index pair [left + 1, right + 1] |
