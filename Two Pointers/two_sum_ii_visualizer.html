167. Two Sum II - Input Array Is Sorted

Given a 1-indexed sorted array numbers and a target, return the two 1-based indices whose values add up to target. Converge left from the start and right from the end.

var twoSum = function(numbers, target) {
let left = 0;
let right = numbers.length - 1;
while (left < right) {
const sum = numbers[left] + numbers[right];
if (sum === target) {
return [left + 1, right + 1];
} else if (sum < target) {
left++;
} else {
right--;
}
}
return [];
};

Iteration Trace

How It Works

  1. The array is already sorted ascending, so small values sit on the left, large on the right.
  2. Compute sum = numbers[left] + numbers[right].
  3. If sum < target, move left right to grow the sum.
  4. If sum > target, move right left to shrink the sum.
  5. If sum === target, return the 1-based indices [left + 1, right + 1].
