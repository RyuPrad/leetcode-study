## Variable Pattern

| Name | Meaning |
|---|---|
| nums | the numbers |
| max | largest number |
| points | points[v] = v × (how many times v appears) |
| num | number being counted |
| take | best total when the current value v is taken |
| skip | best total when v is skipped |
| v | value being decided |
| takeV | best total if v is taken: it must skip v - 1 |
