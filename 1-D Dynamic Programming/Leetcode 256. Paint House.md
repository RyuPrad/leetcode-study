## Variable Pattern

| Name | Meaning |
|---|---|
| costs | costs[i] = [red, blue, green] price for house i |
| dp | cheapest total so far ending with each color |
| i | house being painted |
| red | cheapest total ending with house i red |
| blue | cheapest total ending with house i blue |
| green | cheapest total ending with house i green |
