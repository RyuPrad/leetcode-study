## Variable Pattern

| Name | Meaning |
|---|---|
| s | the text |
| numRows | rows of the zigzag |
| rows | text collected in each row |
| row | row the next character goes to |
| step | +1 while moving down, -1 while moving up |
| c | character being placed |
