## Variable Pattern

| Name | Meaning |
|---|---|
| instructions | moves repeated forever: G forward, L turn left, R turn right |
| dirs | unit steps for north, east, south, west |
| x | east-west position |
| y | north-south position |
| d | index of the facing direction in dirs |
| c | instruction being run |
