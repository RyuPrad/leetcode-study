## Variable Pattern

| Name | Meaning |
|---|---|
| grid | the m × n grid |
| k | number of shifts |
| m | rows |
| n | columns |
| total | number of cells, m × n |
| res | the shifted grid |
| i | position of a cell in row-major order |
| target | position that cell moves to |
