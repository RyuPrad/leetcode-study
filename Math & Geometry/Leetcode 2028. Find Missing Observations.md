## Variable Pattern

| Name | Meaning |
|---|---|
| rolls | the m observed dice rolls |
| mean | average of all n + m rolls |
| n | number of missing rolls |
| m | number of observed rolls |
| missing | total the missing rolls must add up to |
| roll | observed roll being subtracted |
| res | the missing rolls |
| i | roll receiving one of the leftover points |
