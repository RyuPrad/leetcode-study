## Variable Pattern

| Name | Meaning |
|---|---|
| n | side length |
| matrix | the n × n result being filled |
| top | first unfilled row |
| bottom | last unfilled row |
| left | first unfilled column |
| right | last unfilled column |
| value | next number to write |
| c | column being filled along a row |
| r | row being filled along a column |
